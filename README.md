# Sector-Specific Thoughts

This repository contains reusable observations, reference material and architectural insights relating to specific sectors and operating environments.

Content should be generalised and sanitised so that it remains reusable across organisations within a sector and does not disclose organisation-specific information.

Examples:

- Central & Local Government
- Arm's-Length Bodies (ALBs)
- Private Sector Enterprises

The objective is to capture what makes a sector distinctive from an architectural, organisational, information and operational perspective.

If a document answers the question *"What is characteristic about this sector that an architect should understand?"*, it probably belongs here.
